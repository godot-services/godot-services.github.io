godot-services

Open-source tooling for Godot projects.

gd usable

Package manager for Godot: installs addons from the Asset Library or Git, pinned and verified via a lockfile. Also manages Godot editors and export templates.

go install github.com/godot-services/gd@latest

github.com/godot-services/gd

gdar early

Godot Asset Registry: a server to host your own assets for gd.

github.com/godot-services/gdar

Godot Toolbox early

Tray app to install Godot versions, open your projects and manage addons, built on top of gd.

github.com/godot-services/godot-toolbox
