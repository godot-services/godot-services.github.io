# godot-services.github.io

Landing page of the godot-services organization, served by GitHub Pages from `main`.

Repos with Pages enabled show up under this site, e.g. `godot-services.github.io/gd`.

## Custom domain

To serve the site at `godot.services`:

1. Point the DNS of `godot.services` to GitHub Pages (A records `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`).
2. Add a `CNAME` file containing `godot.services`.
